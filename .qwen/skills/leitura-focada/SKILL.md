# Leitura focada de código

## Objetivo
Resolver tarefas de programação usando o menor
contexto possível, sem comprometer a precisão.

## Investigação
1. Identifique o objetivo antes de ler arquivos.
2. Localize arquivos relevantes por nome ou busca.
3. Leia no máximo 3 arquivos por rodada.
4. Prefira trechos específicos a arquivos completos.
5. Não leia novamente arquivos já analisados,
   exceto quando houver alterações relevantes.
6. Não investigue módulos não relacionados.
7. Evite arquivos de build, logs e dependências.
8. Antes de ampliar a investigação para mais de
   5 arquivos, justifique a necessidade.

## Desenvolvimento
1. Respeite a arquitetura existente.
2. Faça alterações pequenas e específicas.
3. Preserve os padrões de Java e Spring Boot.
4. Execute somente os testes relacionados.
5. Não faça refatorações não solicitadas.

## Respostas
- Responda em português brasileiro.
- Seja objetivo.
- Evite explicações conceituais não solicitadas.
- Não repita resultados de ferramentas.
- Resuma o diagnóstico em até 8 linhas.
- Apresente detalhes adicionais somente
  quando necessários ou solicitados.
